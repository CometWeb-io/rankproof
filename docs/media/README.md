# README media

`overview.svg` is an editable workflow diagram based on the checked-in project. It contains no external image or font requests. Text alternatives are included in the main README.

`cli.gif` and `cli.png` are animated/static excerpts of `node bin/rankproof.mjs help`, captured locally from this checkout. The animation presents actual command output, not a network scan or screen recording.

`app.png` and `verify.png` capture the built web app (1.1.0), made with Playwright on 14 November 2026 at 1440×900, device scale 2: the Verify links page before a run, and the results of **Show an example**. The example runs bundled HTML for fictional `.example` domains through the real extractor without network requests, so no real site, account or private data is shown. `app.png` is also used by the landing page in `site/`.
