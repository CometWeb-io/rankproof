Three verdicts

A blocked page is not a lost link

A yes/no checker has to call every failed fetch "lost". RankProof keeps couldn't check apart from not there, and records how far each negative reaches.

01 · INPUT

Your pair

A source page and the exact target URL it should link to.

source_url → target_url
02 · FETCH

Fetch safely

SSRF-guarded request, robots respected, redirects re-checked hop by hop.

http_status · final_url
03 · READ

Read the HTML

Every anchor extracted with its raw href, text, rel and placement.

html-anchor-v4
04 · MATCH

Match exactly

Scheme, host, path and query must match. Fragments are ignored.

exact-http-url-v2
05 · VERDICT

One of three

confirmed not_found error

Get started

              
From clone to first verdict

            

            

              Node.js 22 or newer. RankProof is not on npm yet, so it runs from a clone, on your
              machine, against your list.
            

          

          

            

              

                
              

              
STEP 1

              
Install

              
Clone the repository and install its dependencies.

              

                $ git clone https://github.com/CometWeb-io/rankproof.git $ cd
                rankproof && npm ci
              

            

            

              

                
              

              
STEP 2

              
Start the API

              
It binds to loopback. Set a token before you expose it anywhere.

              
$ npm run api -- \ --host 127.0.0.1 --port 8787

            

            

              

                
              

              
STEP 3

              
Verify your links

              
Up to 50 pairs per request, answered in the order you sent them.

              

                $ curl -sX POST \ 127.0.0.1:8787/v1/backlinks/verify \ -H 'content-type:
                application/json' \ -d @links.json

What it won't claim

              
Honest about its limits

            

            

              A verification tool is only as useful as your understanding of what a result does not
              cover.
            

          

          

            

              

                

                  
                

                01
              

              
No JavaScript rendering

              

                Links injected by scripts after load are not seen. not_found covers fetched HTML
                only.
              

            

            

              

                

                  
                

                02
              

              
Not a Google signal

              
It tells you a link exists and how it is marked up, not how Google values it.

            

            

              

                

                  
                

                03
              

              
Not a web-scale index

              

                Verification checks the pairs you supply. Discovery of unknown links is partial and
                labelled as such.
              

            

            

              

                

                  
                

                04
              

              
Heuristics aren't measurements

              

                Authority, traffic and difficulty scores in the wider toolkit are documented
                heuristics, not third-party data.
